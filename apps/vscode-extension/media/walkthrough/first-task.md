# Your first task

Open a project folder, then describe a change in the agent panel, for example:

> Add a dark mode toggle to the header.

- **Approvals:** anything risky waits for you. Allow it once, for the session, or deny it.
- **Timeline:** every file read, edit and command the agent runs is listed, as it happens.
- **Revert turn:** undoes all of a turn's file changes, byte for byte.
